# Stage 6: Inventive-Step

## Enter this stage when

- the user asks for 创造性主线
- D1 and Dx checks are complete
- the current effective claim set is fixed

## Required baseline

- current effective claim set
- confirmed D1 and Dx check outputs
- final distinguishing-feature set for the current effective claims
- examiner Article 22.3 reasoning chain from Stage 2
- specification-supported effect evidence for each final distinguishing feature

## Task focus

- run the three-step method on the current effective claims
- reconstruct the actual technical problem from the effects of the final distinguishing features
- run the seven-rule check and rank each rule by usefulness
- apply the distinguishing-feature three-filter test: claim construction, prior-art disclosure, and function calibration
- test whether the actual technical problem is neither too broad nor written as the distinguishing feature itself
- identify the precise break in the examiner's obviousness chain before drafting any final paragraph

## Deliverable

- inventive-step overview
- feature-effect-problem table
- seven-rule assessment table
- main and support argument map
- near-final argument paragraphs
- examiner-chain table with chain-break labels
- teaching-and-motivation table comparing each Dx or common-knowledge source with the actual technical problem

## Guardrails

- do not write the distinguishing features into the technical problem
- do not derive the final technical problem from a superseded claim set
- treat distinguishing features and technical problem wording as confirmation checkpoints
- do not equate disclosure with technical teaching
- do not rely on advantages that are not caused by the final distinguishing features
- do not give all seven rules equal weight; make one or two chain breaks carry the argument

## Analysis sequence

1. Restate the live claim baseline and the examiner's Article 22.3 chain.
2. Confirm the closest prior art is a realistic starting point for the actual technical problem.
3. Determine final distinguishing features with the three-filter test.
4. Map each distinguishing feature to its technical effect and specification support.
5. Draft the actual technical problem as a technical task, not as the solution.
6. For each Dx or common-knowledge source, compare disclosure, function, effect, and combination fit.
7. Rank the chain-break points and choose the main line.
8. Draft concise paragraphs in this order: conclusion, D1 fact correction if any, distinguishing features, technical effect, actual technical problem, no teaching or no motivation, and final Article 22.3 conclusion.

## Preferred tables

| Item | What to record | Use in draft |
| --- | --- | --- |
| Examiner chain | D1, differences, problem, Dx, motivation | Shows where the rejection depends on a weak link |
| Feature-effect-problem | final distinguishing feature, effect, support, problem wording | Prevents unsupported or hindsight technical problems |
| Teaching source | Dx/common knowledge, disclosed means, original function, fit with problem | Separates disclosure from technical teaching |
| Argument ranking | chain break, strength, risk, draft role | Keeps weak points out of the main paragraph |
