# Stage 9: QC

## Enter this stage when

- the user asks for QC
- the response draft is already written
- a final pre-submission audit is needed

## Required baseline

- final or near-final response draft
- current effective claim set
- any amended claim text or replacement-page output
- key intermediate analysis if needed for consistency checking

## Task focus

- check logic, legal reasoning, amendment consistency, and wording
- label issues as high, medium, or low risk
- give replacement wording or fix direction for each high-risk point
- verify that the Article 22.3 chain is complete and that the chosen rebuttal breaks a specific link
- check whether technical teaching and motivation are supported by same-function analysis, not just feature matching

## Deliverable

- overall readiness conclusion
- prioritized issue list
- consistency check table
- suggested replacement text
- Article 22.3 readiness table covering claim baseline, distinguishing features, effects, technical problem, teaching, motivation, and conclusion

## Guardrails

- do not re-analyze the whole case from scratch
- do not give vague praise without concrete issues
- flag as high risk if the technical problem contains the distinguishing feature, if the effect lacks support, or if amended and unamended claim baselines are mixed

## Article 22.3 QC checks

1. The current effective claim set is the only claim set used in the final argument.
2. The final distinguishing features match the claim text exactly.
3. Each asserted technical effect is caused by a final distinguishing feature and has specification or common-knowledge support.
4. The actual technical problem is a technical task, not the solution.
5. D1 is treated as a realistic starting point only if it faces the same improvement target.
6. Each Dx or common-knowledge source is tested for disclosure, same function, and combination fit.
7. The main paragraph attacks a concrete chain break instead of listing invention advantages.
8. The conclusion is no stronger than the established chain-break analysis.
