# 无效过程梳理内部说明

这个阶段的目标不是简单做时间线，而是同时完成四件事：

1. 还原程序过程
2. 还原双方攻防主线
3. 找出真正焦点
4. 为口审准备、内部汇报、客户沟通或决定分析提供可复用中间成果

## 基本顺序

1. 盘点案卷材料，按国家局发文、请求人发文、专利权人发文分类
2. 先做程序时间线
3. 再做请求人首轮攻击和我方答辩与修改
4. 再看后续转送文件或补充意见
5. 最后提炼口审前真正焦点

## 强制区分

- 原权利要求 vs 修改后权利要求
- 程序文件 vs 实体文件
- 请求人主张 vs 我方立场
- 已确认事实 vs 分析判断

## 标准输出

- 材料清单
- 文件来源分类表
- 程序时间线
- 攻击/答辩框架摘要
- 修改后权利要求影响说明
- 口审前真正焦点
