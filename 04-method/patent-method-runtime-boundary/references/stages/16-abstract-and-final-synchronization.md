# Stage 16: Abstract And Final Synchronization

## Enter this stage when

- the user asks for stage 16
- the user asks for 摘要, 整稿同步, 全文重写, or final packaging
- the operative claim chain is fixed

## Required baseline

- confirmed claim set
- confirmed invention content
- confirmed embodiments
- confirmed figure plan
- current `.docx` file if the work is document-based

## Task focus

- draft or revise the abstract from the adopted claim chain
- synchronize abstract figure, flowchart, figure legends, and section text
- verify that claims, invention content, embodiments, abstract, and figures reflect the same method boundary
- perform final package checks, including stale-step scan and basic document validation
- when a patent Word template is available, create a working copy from the template and fill only the corresponding body sections

## Deliverable

- abstract
- synchronized full draft or synchronized DOCX copy
- final consistency note

## Guardrails

- do not leave one section on an old step chain while other sections use the new chain
- do not let the abstract solve a problem that the adopted claim chain cannot actually solve
- do not rewrite template formatting when the task is template filling; preserve the template's existing font, size, spacing, headers, footers, and non-body layout
- when filling a template, change only the target正文 content unless the user explicitly asks for broader document edits

## Stop rule

Stop after the synchronized final draft and final consistency note.
