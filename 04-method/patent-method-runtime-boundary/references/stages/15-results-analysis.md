# Stage 15: Results Analysis

## Enter this stage when

- the user asks for stage 15
- the user asks for 结果分析
- the retained test items and retained result tables are fixed

## Required baseline

- final retained result tables
- confirmed examples and comparative examples
- confirmed technical-effects logic

## Task focus

- compare examples and key comparative examples
- explain the technical meaning of retained metrics
- connect metric differences back to the inventive method route
- before attributing differences to the inventive route, confirm the comparison basis is controlled; for pigments, color pastes, fillers, or active additives, analysis should say whether values were normalized by effective component content or total addition amount
- avoid claiming more than the retained results actually support
- keep the results analysis brief for preparation-heavy or material-preparation cases unless the user asks for depth
- do not say the retained data prove inventiveness; instead, identify which retained technical means played the key role in achieving the retained effects

## Deliverable

- results-analysis text for the specification

## Guardrails

- do not cite deleted tables or deleted metrics
- do not infer conclusions the retained results cannot support
- do not rely on a deleted process-label or method-label column to explain the table; describe the technical route in prose only if that route remains in the examples or comparative examples

## Stop rule

Stop after the results analysis unless the user explicitly requests a specific revision or final packaging.
