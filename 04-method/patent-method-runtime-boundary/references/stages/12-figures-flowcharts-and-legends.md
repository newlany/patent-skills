# Stage 12: Figures, Flowcharts, And Legends

## Enter this stage when

- the user asks for stage 12
- the user asks for 附图规划, 流程图, 图例, or figure consistency
- the claim chain and embodiment baseline are fixed

## Required baseline

- confirmed claim set
- confirmed embodiments
- current figure list if available

## Task focus

- determine which figures are actually needed
- default to a flowchart when the inventive point is the runtime method chain
- add structural or equipment figures only when they are needed to explain claimed steps or recurring terms
- make figure legends track the adopted claim chain and term set
- draft or revise the required flowchart or figure set when the user wants drawing output rather than planning only
- update abstract-figure planning together with the main figure planning

## Deliverable

- figure plan
- figure legend text
- any required flowchart or figure revision instructions
- when the case is at drawing-output stage, the draft flowchart or figure file set itself

## Guardrails

- do not keep obsolete figures just because they appeared in an earlier draft
- do not let the flowchart preserve stale steps from a superseded claim chain
- if the user asks for figures to be drawn, do not stop at planning only

## Stop rule

Stop after the figure plan and wait for confirmation before cleanup or final synchronization.
