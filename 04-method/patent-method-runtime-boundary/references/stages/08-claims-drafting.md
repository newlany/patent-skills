# Stage 8: Claims Drafting

## Enter this stage when

- the user asks for stage 8
- the claim-layout memo is confirmed
- the case needs formal claim text

## Required baseline

- confirmed claim-layout memo
- confirmed final disclosure

## Task focus

- draft formal method claims using objective process wording
- keep claim 1 centered on the inventive technical-means main line and include the necessary technical features for solving the stated technical problem
- keep claim 1 focused on the runtime method chain
- for method claims, describe the invention with process steps, operating conditions, or flow wording rather than result-only or preference-style language
- when a parameter is needed to delimit the claim scope, draft it as a disclosure-supported numeric range by default rather than a single absolute value; treat fixed-point values as an exception that needs a clear technical reason
- use Chinese full technical names in the claims when a standard Chinese name exists; avoid untranslated English abbreviations for raw materials, components, or technical terms
- explicitly show the runtime function of any support resource recited in claim 1
- if a dependent claim is meant to define how a pre-existing support resource is updated after the main chain, draft that claim from the support-resource perspective by default rather than by mechanically adding another runtime step
- use dependent claims as real fallback positions
- default to single-reference dependent claims when drafting a fresh claim set; use multi-dependent claims only when strategically necessary and keep them in strict alternative form
- renumber and self-check every step reference after any chain reset

## Deliverable

- formal claim set
- short self-check note

## Guardrails

- avoid vague, purely functional, or result-only language
- avoid unclear claim terms such as `优选`、`最好是`、`尤其是`、`必要时`、`例如`、`约`、`接近`、`等`
- do not use a single-point process parameter in the claim set where a supported range is available and better matches the desired protection scope
- do not use English abbreviations in the claims for terms that already have a settled Chinese technical name
- do not let dependent claims create an illegal reference chain: dependent claims may cite only earlier claims; a multi-dependent claim must use `或` / `任一` style alternative citation and must not be used as the basis of another multi-dependent claim
- do not let claim 1 narrate historical accumulation as though it happens in every current run unless the disclosure truly supports that
- do not rewrite a support-resource update limitation into a purpose-heavy clause such as `写入后用于后续...` when the user's adopted claim baseline instead treats the inventive point as the resource being updated through that write operation

## Stop rule

Stop after the formal claim set and wait for confirmation before section drafting.
