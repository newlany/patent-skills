# General Method Patent Stage Routing Map

Use this map to route a user request to exactly one stage unless the user clearly wants the full workflow.

| Stage | Typical requests | Reference |
| --- | --- | --- |
| 1 | disclosure analysis, 披露分析, 缺陷审查 | `stages/01-disclosure-analysis.md` |
| 2 | disclosure reconstruction, 披露重构, 工艺链补全 | `stages/02-disclosure-reconstruction.md` |
| 3 | method boundary, 方法边界, 前置步骤, 建库是否入主权 | `stages/03-method-boundary-alignment.md` |
| 4 | core feature analysis, 核心特征分析, 技术问题, 关键技术手段, 最小特征集 | `stages/04-core-feature-analysis.md` |
| 5 | inventive-step analysis, 创造性分析, 区别点主线 | `stages/05-inventive-step-analysis.md` |
| 6 | final disclosure, 最终交底书, 最终技术基线 | `stages/06-final-disclosure.md` |
| 7 | claim layout, 权利要求布局, claim 1 主题设计 | `stages/07-claim-layout.md` |
| 8 | claims drafting, 权利要求书撰写 | `stages/08-claims-drafting.md` |
| 9 | background drafting, 背景技术 | `stages/09-background-drafting.md` |
| 10 | invention content, 发明内容, 技术效果 | `stages/10-invention-content-drafting.md` |
| 11 | embodiments, 具体实施方式, 实施例, 对比例 | `stages/11-embodiments-and-examples.md` |
| 12 | figures, flowchart, 图例一致性, 附图规划, 附图绘制, 流程图绘制 | `stages/12-figures-flowcharts-and-legends.md` |
| 13 | formulas, step numbering, DOCX cleanup, 公式修复 | `stages/13-formulas-and-docx-cleanup.md` |
| 14 | testing design, 测试设计, 标准与结果表 | `stages/14-testing-design.md` |
| 15 | results analysis, 结果分析 | `stages/15-results-analysis.md` |
| 16 | abstract, final sync, 摘要, 整稿同步, 全文重写 | `stages/16-abstract-and-final-synchronization.md` |

If the user names a stage number directly, route to that stage.
If the user asks for a later stage without a confirmed baseline, state the missing prerequisite and risk before proceeding.
