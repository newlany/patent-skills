# Stage 10: Process-Detail Drafting

## Enter this stage when

- the user asks for stage 10
- the user asks for 工艺细化 or detailed process description
- the claim set and final disclosure are fixed

## Required baseline

- confirmed claim set
- confirmed final disclosure

## Task focus

- explain each process step in sequence
- cover materials, devices, loading order, control conditions, detection, transfer, and step linkage
- write in specification style, not claim style

## Deliverable

- detailed process-description section for the specification

## Guardrails

- do not cite claim numbers
- do not switch into fixed single-run example values unless the user asks for examples
- do not add effect discussion here

## Stop rule

Stop after the process-description section and wait for confirmation before examples.
