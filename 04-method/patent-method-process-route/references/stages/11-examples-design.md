# Stage 11: Examples Design

## Enter this stage when

- the user asks for stage 11
- the user asks for 实施例设计 or 对比例设计
- the process-description section is fixed

## Required baseline

- confirmed process-detail section
- confirmed claim set
- confirmed final disclosure
- confirmed inventive-step main line

## Task focus

- for material-preparation cases, structure the section as `方案详细说明 -> 实施例和对比例 -> 性能测试`
- in the detailed-scheme part, first write the method as `步骤一、步骤二...` and then explain each step in fuller process detail while folding in dependent-claim ranges and retained process conditions
- if the user asks for no small headings, keep only `实施例1/2/...` and `对比例1/2/...` as local headings, and write the detailed scheme, raw-material paragraph, testing methods, and results analysis as ordinary paragraphs
- in that mode, the opening step-chain paragraphs should directly carry the full independent-claim route with retained parameters and ranges
- before writing `实施例` and `对比例`, add a raw-materials paragraph or compact raw-materials section unless the user explicitly forbids it
- write raw materials in prose with raw-material name, commercial grade or model, and supplier when available; do not default to a raw-material table
- prefer domestic Chinese commercial products when they technically fit the disclosure and claim scope
- complete supplier and grade/model information only from real web evidence, such as supplier pages, TDS, SDS, product catalogs, product manuals, manufacturer pages, or credible marketplace/manufacturer listings; do not invent commercial sources
- when web research is used, cite or record the source in the response or drafting note, while keeping the application text focused on technical implementation rather than web citations
- if reliable commercial-source evidence is missing, use generic technical wording or flag the item for inventor confirmation instead of fabricating a supplier or grade
- keep any web-sourced commercial grade as an embodiment example and add generic fallback wording for the same material type and key functional-property controls so the claim scope is not limited to one supplier
- design at least three implementation examples around the lower bound, optimized value, and upper bound of the retained parameter window unless the user asks for a different example layout
- design comparative examples that directly test the inventive main line and keep them compatible with later testing
- in the testing part, keep only effect-linked test items, use a table for retained data, and keep the results analysis brief without saying the data prove inventiveness

## Deliverable

- examples and comparative examples section in specification style

## Guardrails

- comparative examples must support the inventive-step logic, not random variation
- keep the example design compatible with later testing design
- do not use a commercial grade or supplier as support for a claimed functional property unless the source or a disclosed test actually supports that property

## Stop rule

Stop after the examples section and wait for confirmation before testing design.
