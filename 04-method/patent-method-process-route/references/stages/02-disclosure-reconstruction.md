# Stage 2: Disclosure Reconstruction

## Enter this stage when

- the user asks for stage 2
- stage 1 has identified gaps that must be repaired
- the user wants a technically implementable reconstructed disclosure

## Required baseline

- confirmed stage-1 disclosure analysis or an equivalent issue list
- original disclosure materials
- any user instruction on narrowing direction or preferred technical route

## Task focus

- answer each identified problem
- supplement materials, parameters, devices, process windows, and test conditions
- distinguish repaired facts from assumptions based on common technical knowledge
- converge scattered routes into the strongest authorization-oriented main route

## Deliverable

- problem-by-problem supplementation memo
- complete initial reconstructed disclosure

## Guardrails

- do not jump ahead to formal claims or legal drafting
- keep technically inferred content separate from confirmed facts

## Stop rule

Stop after the reconstructed disclosure and wait for confirmation before feature extraction.
