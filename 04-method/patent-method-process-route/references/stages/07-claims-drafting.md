# Stage 7: Claims Drafting

## Enter this stage when

- the user asks for stage 7
- the claim-layout memo is confirmed
- the case needs formal claim text

## Required baseline

- confirmed claim-layout memo
- confirmed final disclosure

## Task focus

- draft formal method claims using objective process wording
- put key inventive process features into claim 1
- use dependent claims as real fallback positions
- self-check breadth, clarity, and support risk

## Deliverable

- formal claim set
- short self-check note

## Guardrails

- avoid vague, purely functional, or result-only language
- keep claim 1 aligned with the fixed inventive main line

## Stop rule

Stop after the formal claim set and wait for confirmation before background drafting.
