# Stage 12: Testing Design

## Enter this stage when

- the user asks for stage 12
- the user asks for 测试设计, 测试标准, or result-table design
- the examples and comparative examples are fixed

## Required baseline

- confirmed examples and comparative examples
- confirmed claim set
- final disclosure baseline

## Task focus

- choose only test items that support the claimed distinctions and effect logic
- prefer Chinese national standards where appropriate
- write standard numbers, conditions, sample size, environment, equipment, and calculation methods
- organize result tables for later analysis

## Deliverable

- testing-standards section
- result-table design or draft results requested by the user

## Guardrails

- do not add irrelevant tests just to make the section look rich
- keep designed draft data distinct from real measured data

## Stop rule

Stop after the testing design and wait for confirmation before results analysis.
