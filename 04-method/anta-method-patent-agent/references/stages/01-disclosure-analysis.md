# Stage 1: Disclosure Analysis

## Enter this stage when

- the user asks for stage 1
- the user wants a defect review before reconstruction
- the original disclosure must be audited for missing facts, contradictions, or drafting risk

## Required baseline

- original disclosure files
- any inventor notes or internal analyses if available

## Task focus

- separate disclosed facts, completable points, and inventor-confirmation points
- identify missing parameters, materials, devices, steps, and test conditions
- identify contradictions, ambiguity, unsupported generalizations, and process-chain breaks
- explain why each issue matters for later claims, support, clarity, or inventive-step framing

## Deliverable

- disclosure analysis report
- issue list with impact and proposed repair path

## Guardrails

- do not repair the disclosure in this stage
- do not collapse multiple technical routes without saying so

## Stop rule

Stop after the analysis report and wait for confirmation before reconstruction.
