# Stage 13: Results Analysis

## Enter this stage when

- the user asks for stage 13
- the user asks for 结果分析
- the final retained result tables are fixed

## Required baseline

- final retained result tables
- confirmed examples and comparative examples
- confirmed technical-effects logic

## Task focus

- compare examples and key comparative examples
- explain the technical meaning of retained metrics
- connect metric differences to the inventive process route
- explain why shortcut routes or simple filler increases do not achieve the same overall result

## Deliverable

- result-analysis text for the specification

## Guardrails

- do not cite deleted tables or deleted metrics
- do not infer conclusions the retained results cannot support

## Stop rule

Stop after the results analysis unless the user explicitly requests a specific revision or another downstream packaging step.
