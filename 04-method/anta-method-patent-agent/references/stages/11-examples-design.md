# Stage 11: Examples Design

## Enter this stage when

- the user asks for stage 11
- the user asks for 实施例设计 or 对比例设计
- the process-description section is fixed

## Required baseline

- confirmed process-detail section
- confirmed claim set
- confirmed final disclosure
- confirmed inventive-step main line

## Task focus

- draft raw-material and equipment sections with specific grades or models when available
- design concrete examples centered on the independent claim and fallback ranges
- design comparative examples that directly test the inventive main line

## Deliverable

- examples and comparative examples section in specification style

## Guardrails

- comparative examples must support the inventive-step logic, not random variation
- keep the example design compatible with later testing design

## Stop rule

Stop after the examples section and wait for confirmation before testing design.
