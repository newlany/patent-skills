# Recommended File Naming

When stage outputs are saved to files, keep the names ordered and stable.

Recommended pattern:

- `01_...` disclosure analysis
- `02_...` disclosure reconstruction
- `03_...` core feature analysis
- `04_...` inventive-step analysis
- `05_...` final disclosure
- `06_...` claim layout
- `07_...` claims drafting
- `08_...` background
- `09_...` effects
- `10_...` process-detail drafting
- `11_...` examples and comparative examples
- `12_...` testing design
- `13_...` results analysis

If the user already has an established numbering scheme, follow that scheme instead of forcing a new one.
