# Anta Stage Routing Map

Use this map to route a user request to exactly one stage unless the user clearly wants the full workflow.

| Stage | Typical requests | Reference |
| --- | --- | --- |
| 1 | disclosure analysis, 披露分析, 缺陷审查 | `stages/01-disclosure-analysis.md` |
| 2 | disclosure reconstruction, 披露重构, 补全工艺链 | `stages/02-disclosure-reconstruction.md` |
| 3 | core feature analysis, 核心特征分析, 最小特征集 | `stages/03-core-feature-analysis.md` |
| 4 | inventive-step analysis, 创造性分析, 协同/递进改进分析 | `stages/04-inventive-step-analysis.md` |
| 5 | final disclosure, 最终交底书 | `stages/05-final-disclosure.md` |
| 6 | claim layout, 权利要求布局, claim 1 主题设计 | `stages/06-claim-layout.md` |
| 7 | claims drafting, 权利要求正式撰写 | `stages/07-claims-drafting.md` |
| 8 | background drafting, 背景技术 | `stages/08-background-drafting.md` |
| 9 | effects drafting, 技术效果, beneficial effects | `stages/09-effects-drafting.md` |
| 10 | process detail, 工艺细化, 具体实施方式工艺段 | `stages/10-process-detail-drafting.md` |
| 11 | examples design, 实施例设计, 对比例设计 | `stages/11-examples-design.md` |
| 12 | testing design, 测试设计, 测试标准, 结果表 | `stages/12-testing-design.md` |
| 13 | results analysis, 结果分析 | `stages/13-results-analysis.md` |

If the user names a stage number directly, route to that stage.
If the user asks for a later stage without a confirmed baseline, state the missing prerequisite and risk before proceeding.
