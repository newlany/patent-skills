# Public Commands

Recommended public invocation patterns:

```text
用 $patent-cn 处理这个专利案件，先判断任务类型，再继续推进。
```

```text
用 $patent-cn-draft 根据这份交底撰写中文专利，默认 guided，先完成交底分析和首轮查新。
```

```text
用 $patent-cn-draft 一口气出完整 first pass；遇到低置信路线、关键事实缺口，或者最接近现有技术会改写保护范围时停下来。
```

```text
用 $patent-cn-review 检查这套申请文件，输出确认问题和疑似问题；可自动修复项写入 validation report。
```

```text
用 $patent-cn 根据这份材料生成给发明人的补充问题清单，并导出 DOCX。
```

```text
用 $patent-cn 判断这个任务该走撰写、审查或答复主流程，还是走研究或支撑交付；如果我提到了旧 skill 名，请自动换成新的公共路由。
```

```text
用 $patent-cn 根据这份审查意见先做答复分析，再生成给申请人的沟通简报 DOCX。
```

```text
用 $patent-cn 根据这份驳回决定生成复审分析及建议 DOCX。
```

```text
用 $patent-cn 根据这份查新结果生成给客户的检索结果简报 DOCX。
```

```text
用 $patent-cn-response 处理这个审查意见，先拆解审查意见和 D1/D2/D3，再判断是否修改权利要求。
```

```text
用 $patent-cn-doctor 检查本地专利系统依赖是否齐全。
```
