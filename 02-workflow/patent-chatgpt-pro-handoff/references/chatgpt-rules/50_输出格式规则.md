# 输出格式规则

请按任务输出结构化结果，方便 Codex 后续整合。

权利要求任务建议输出：

1. 技术问题链；
2. 独立权利要求边界说明；
3. 权利要求书草案；
4. 从属权利要求退让层级说明；
5. 支持依据与风险；
6. 需要确认的问题。

说明书任务建议输出：

1. 章节结构；
2. 可直接使用的中文正文；
3. 与权利要求的对应关系；
4. 支持依据与风险；
5. 需要确认的问题。

答复任务建议输出：

1. 审查意见拆解；
2. 对比文件事实；
3. 修改方案；
4. 答复主线；
5. 可直接使用的答复段落；
6. 风险和待核查事项。

除非任务要求最终成文，请不要只输出一篇连续长文。请保留分析层和成文层，方便后续复核。
