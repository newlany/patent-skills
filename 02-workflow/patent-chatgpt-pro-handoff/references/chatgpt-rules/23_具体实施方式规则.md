# 具体实施方式规则

具体实施方式应当让本领域技术人员能够实施发明。不要只把权利要求改写成段落。

结构类案件需要说明部件的物理形态和位置关系，并解释连接关系、方向关系以及协同方式。对于“对应”“重合”“间隔”“连通”“阵列状”等关系词，应说明它们在成品结构中如何识别。

方法类案件需要说明每个步骤接收的输入和处理方式，再说明输出结果以及触发条件。不要把预处理和训练写成运行步骤，也不要把配置、运行步骤以及结果评价混在同一层级，除非材料明确要求这样布局。

软件或算法案件需要区分运行时方法和离线训练，并把参数配置、模型更新与在线处理流程分清楚。每个步骤应当说明处理对象、处理方式以及产生的数据结果。

实施例可以包含可选方案，但必须标明可选属性。不要把示例参数写成必要条件，除非权利要求策略要求收窄。
