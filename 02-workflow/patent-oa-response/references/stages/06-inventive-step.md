# Stage 6: Inventive-Step

## Enter this stage when

- the user asks for 创造性主线
- D1 and Dx checks are complete
- the current effective claim set is fixed

## Required baseline

- current effective claim set
- confirmed D1 and Dx check outputs
- final distinguishing-feature set for the current effective claims

## Task focus

- run the three-step method on the current effective claims
- reconstruct the actual technical problem from the effects of the final distinguishing features
- run the seven-rule check and rank each rule by usefulness

## Deliverable

- inventive-step overview
- feature-effect-problem table
- seven-rule assessment table
- main and support argument map
- near-final argument paragraphs

## Guardrails

- do not write the distinguishing features into the technical problem
- do not derive the final technical problem from a superseded claim set
- treat distinguishing features and technical problem wording as confirmation checkpoints
