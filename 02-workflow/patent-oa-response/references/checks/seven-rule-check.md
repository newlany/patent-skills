# Seven-Rule Check

Run these rules only after the current effective claim set is fixed.

1. Technical problem is not hindsight-driven.
2. D1 lacks the premise for the technical problem.
3. Dx truly discloses the cited feature.
4. Dx uses the feature for the same function.
5. D1 + Dx can be combined without major conflict.
6. The effect is predictable or not.
7. The claimed solution is directly obtainable or not.

## Ranking rule

Do not give equal weight to every rule. Mark each rule as:

- main point
- support point
- not useful

## Guardrails

- Do not write distinguishing features into the technical problem.
- Do not apply the rules to a superseded pre-amendment claim set.
- If a rule is weak, say so directly instead of padding the draft.
