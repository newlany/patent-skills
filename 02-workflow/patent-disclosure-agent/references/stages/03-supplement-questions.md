# Stage 03: 需要发明人补充说明的问题清单

## 进入条件

- 用户要给发明人出补料问题。
- 用户要把 disclosure 缺口转成可答复问题。
- 案件还不能进入撰写阶段，需要确认少数关键事实。

## 内容规则

Draft this file by applying:

```text
/Users/chrynos/.codex/skills/patent-inventor-questions/SKILL.md
```

The list is for inventor communication, not for recording every internal defect. Ask only questions whose answers are needed before drafting can proceed. If a point can be determined from the disclosure, common general knowledge, prior analysis, or a reasonable drafting assumption, do not ask the inventor.

Before writing, reconstruct the likely technical problem, the core solution, the candidate independent-claim boundary, and the effect chain. Use that reconstruction only as an internal filter. The final document should contain only the questions.

## 输出要求

- Write the result to `03_需要发明人补充说明的问题清单.md`.
- Do not divide the final list into chapters.
- Use direct numbered items: one issue per number.
- Prefer the pattern `原文片段：“……”` or `上下文：……`, followed by `问题：……`.
- Default to 3 to 8 questions. Exceed 10 only when real draftability blockers remain.
- Avoid broad prompts such as “请补充技术方案” or “请详细说明技术效果”.
- Use natural Chinese and avoid dense strings of ideographic commas.

If no key supplement question is needed, say so briefly and list the drafting assumptions outside the inventor-facing question list.
