# 技术交底分析调用模板

请使用 `$patent-disclosure-agent` 对以下技术交底材料执行端到端分析：

- 源文件：`<在这里填写交底书绝对路径>`
- 输出目录：`<可选；默认放在源文件目录下的 交底分析输出/源文件名>`

执行要求：
1. 若源文件为 `.docx` 且包含公式，先调用 `$patent-docx-math` 提取保留公式的中间稿，再开始分析。
2. 按顺序生成并填写三份工作稿：`01_技术交底分析报告.md`、`02_技术交底逻辑重构与缺陷审查报告.md`、`03_需要发明人补充说明的问题清单.md`。
3. 缺陷审查与问题清单中，问题定位方式统一使用“步骤编号/章节标题/附图编号/原文片段”，不要使用 `P110` 之类段落号。
4. 问题清单每条先写原文片段或问题内容，再提出自然、专业、便于研发答复的补充问题。
5. 分析完成后导出三份 `.docx` 正式稿，确保公式按 Word 数学公式呈现，不是普通字母文本。
6. 更新 `00_交底分析任务索引.md`，写明每个步骤和正式稿导出状态。
